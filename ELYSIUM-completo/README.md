# Elysium

Elysium é uma plataforma voltada para gerenciamento e execução de Crônicas de **Vampiro: A Máscara V5**.

A ideia nasceu como um projeto pessoal para reunir ficha, rolagens, gerenciamento de Crônicas e ferramentas para o Mestre em uma experiência mais integrada, imersiva e voltada especificamente para V5.

O projeto ainda está em desenvolvimento.

---

## Tecnologias

Atualmente o Elysium utiliza:

- HTML
- CSS
- JavaScript
- Node.js
- SQLite

A interface foi construída sem frameworks de frontend.

---

## Sobre o desenvolvimento

Comecei o Elysium principalmente como uma forma de colocar em prática o que venho estudando em desenvolvimento web.

Tenho conhecimento em HTML, CSS e JavaScript e venho expandindo meus estudos para backend, banco de dados, organização de aplicações e arquitetura conforme o projeto cresce.

Com o tempo, o Elysium acabou ficando consideravelmente maior do que a ideia inicial e passou a envolver áreas que eu ainda estou aprendendo. Por isso, algumas partes do projeto foram desenvolvidas com apoio de ferramentas de inteligência artificial, principalmente para me ajudar a estruturar, implementar e compreender funcionalidades que estavam além do que eu conseguiria construir sozinho naquele momento.

Ainda assim, tento acompanhar o código, entender as decisões tomadas e usar o próprio projeto como parte do meu processo de aprendizado.

Não considero o Elysium uma referência de arquitetura perfeita, um produto final ou uma demonstração definitiva da forma como eu desenvolveria uma aplicação profissional em produção.

Existem decisões que provavelmente serão revistas, partes que serão refatoradas e implementações que podem mudar conforme eu ganho mais experiência.

Prefiro enxergar o Elysium como um laboratório: um projeto em que posso testar ideias, errar, refatorar, experimentar tecnologias e aprender no processo.

Feedback é muito bem-vindo.

## Objetivo

O objetivo do Elysium não é ser um VTT genérico.

A proposta é criar uma ferramenta pensada especificamente para **Vampiro: A Máscara V5**, dando mais espaço para elementos como:

- Crônicas
- personagens e fichas V5
- Fome e Humanidade
- rolagens e Dados de Fome
- ferramentas para o Mestre
- cenas
- NPCs
- notas e informações secretas
- diário da Crônica
- eventos narrativos
- ambientação e mídia
- conflitos
- mapas
- timeline
- relógios narrativos
- progressão de personagens
- organização de Atos e Episódios

A filosofia do projeto é simples:

> **O jogador joga uma Crônica. O Mestre dirige uma Crônica.**

# Como usar

Existem algumas formas de executar o Elysium.

A mais simples para quem só quer jogar é utilizar o executável no Windows.

Para desenvolvimento, o projeto também pode ser executado normalmente com Node.js.

---
