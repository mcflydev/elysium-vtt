Sua mesa em poucos cliques.

O computador do Mestre hospeda o Elysium. Os jogadores só precisam estar na mesma rede do Radmin e abrir o endereço abaixo no navegador.

Endereço para compartilhar Detectando Radmin... Verificando as interfaces de rede deste computador.
01

Se você é o Mestre

  1. Abra o Radmin VPN e crie ou entre em uma rede.
  2. Abra o Elysium.exe. O servidor inicia sozinho e esta página abre automaticamente.
  3. Na primeira execução, se o Windows perguntar sobre Firewall, permita o acesso em Redes privadas.
  4. Copie o endereço detectado acima e envie para os jogadores.
  5. Mantenha o Elysium rodando enquanto a sessão estiver acontecendo.
02

Se você é Jogador

  1. Abra o Radmin VPN e entre na mesma rede do Mestre.
  2. Peça ao Mestre o endereço do Elysium. Ele será parecido com http://26.x.x.x:3000.
  3. Cole o endereço na barra do Chrome, Firefox, Edge ou outro navegador.
  4. Crie sua conta ou faça login.
  5. Entre na Crônica pelo convite enviado pelo Mestre.

Não conectou?

1. Confirme que todos aparecem online na mesma rede do Radmin.

2. Confirme que o endereço começa com o IP do Mestre no Radmin e contém a porta exibida.

3. No PC do Mestre, permita o Elysium/Node no Firewall do Windows para redes privadas.

4. O jogador não deve usar localhost. Esse endereço só funciona no computador que está hospedando.

O banco da mesa continua no computador do host. O Radmin funciona apenas como a rede que conecta os participantes ao servidor local do Elysium.
